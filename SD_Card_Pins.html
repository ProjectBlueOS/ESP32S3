Configuration

Setting Value Notes
Bus Mode SPI Default; SDMMC fallback available

DMA SDSPI_DEFAULT_DMA
Max Transfer 16384 bytes

Format on Fail false

Notes

Internal Pullups: SDMMC 1-bit mode enables internal pullups on all data lines. SPI mode uses the same physical pins but in a different protocol — CS (GPIO 4) must be driven high during SDMMC init to prevent SPI mode entry.
Skip Guard: If SD_MOSI_PIN or SD_SCK_PIN are set to -1, SD card initialization is skipped entirely.
